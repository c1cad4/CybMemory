# CybMemory

Хранение и поиск знаний

## Реализовано

SQLite WAL, полнотекстовый FTS5-поиск и обязательный источник для каждого знания. Знания и результаты задач долговременны. Атомарный execute_once предотвращает повторные записи при конкурентных retry; сбой откатывает записи всей задачи.

## Проверка

```bash
python3 -m unittest discover -s tests -v
```
